# Portal de Notícias — POO

## Descrição

Projeto em Java desenvolvido com foco em Programação Orientada a Objetos, simulando um portal de notícias com estrutura organizada em classes.

## Tecnologias

- Java

## Funcionalidades

- Estruturação de classes
- Organização de dados
- Separação de responsabilidades

## Objetivo do Projeto

Aplicar conceitos de POO como classes, objetos e organização de sistemas em um projeto prático.
